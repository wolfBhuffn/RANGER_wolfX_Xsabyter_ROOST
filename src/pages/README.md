## ⚡ Overview

**RANGER_wolfX_Xsabyter_ROOST** is a high-performance, dark-themed personal command center and operational suite. Designed for high-stress multi-domain environments, it merges career-specific human services workflows (SCFU shift tracking, automated overtime, and comprehensive documentation generation) with real-time financial tracking, banking cashflow management, and an AI-driven task dispatcher powered by a custom multi-model fallback array (`gemini-2.0-flash` / `gemini-1.5-flash`).

Protected by a master passkey security gateway with custom analog CRT signal glitch transitions and physical sculpture-inspired branding, this system serves as an uncompromised digital workspace.

---

## 🔒 Core Architecture & Modules

* **Master Authentication & Security Gate**: Unrestricted operator permissions secured via master passkey (`0000`). Locked modules trigger an analog TV static and signal-tearing glitch sequence featuring the **Ranger** and **Roost** identity busts.
* **SCFU Shift, Timer & Payroll Engine**: Live day-hab shift tracking configured for standard windows (`6:30am | 3:30pm`) with automated overtime calculation (1.5x) for early clock-ins or late clock-outs, paired with tax and net take-home paycheck breakdowns.
* **Daily & Monthly Document Generator**: Dynamic template generator supporting *ABC Occurrence Logs*, *Life Skills & Functional Academics*, *Community Outings*, *AMAP Medication Administration Records (MAR)*, *Incident Reports*, and *Monthly Service Summaries*.
* **Capital & Cashflow Vault**: Aggregated asset and liability tracking across checking vaults, SoFi savings, M&T auto loans, and Amex statements, protected by neon financial status indicators and blur-effect privacy gates.
* **AI Agent Task Dispatcher**: Integrated terminal interface dispatching instructions to backend AI routing pipelines with real-time execution logs.

## 🛠️ Tech Stack

* **Frontend**: React, TypeScript, Tailwind CSS, Vite
* **Backend / Routing**: Custom Python server engine (`http.server` / API routing)
* **Design System**: Dark editorial glassmorphism, CRT scanline overlays, chromatic aberration effects, and custom visual identity assets (`bust-ranger.jpg`, `bust-roost.jpg`).
